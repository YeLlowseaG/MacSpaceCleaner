# Mac 空间清理使用说明

## 如何运行

双击桌面上的 **Mac 空间清理.app**。

如果 macOS 第一次阻止打开：

1. 在访达中右键该文件。
2. 选择“打开”。
3. 在提示窗口中再次选择“打开”。

## 功能

- 显示当前磁盘可用空间和预计可释放空间。
- 扫描可安全删除的开发工具和应用缓存。
- 自动识别旧版 Xcode 模拟器，并保留每个平台的最新版本。
- 使用 Xcode 官方命令删除旧运行时和共享缓存。
- 每个项目都可以单独勾选或取消。
- 点击清理项右侧的 ⓘ，可以查看真实目录、子文件和文件夹、大小及修改时间；文件夹支持继续逐层查看。
- 详情窗口可以直接在访达中定位当前目录或文件。
- 点击“一键清理”后仍会显示最终确认窗口。

工具将清理项分为三类：

- **建议清理**：已核实的缓存和日志，默认勾选。
- **可选清理**：可能重新下载资源或影响离线内容，默认不勾选。
- **仅查看的个人数据**：下载、iCloud、微信聊天数据和 WPS 自动备份，只显示大小并提供访达入口，不参与一键清理。

## 工具不会自动删除的内容

- 下载和桌面文件
- iCloud 文件
- 微信聊天、图片、视频和附件
- WPS 文档及自动备份
- 项目源码
- 浏览器书签、密码和登录信息
- 每个平台最新版本的 Xcode 模拟器

## 注意事项

- 清理前建议退出 Xcode、Simulator、Cursor、Chrome 和微信开发者工具。
- 清理缓存后，部分应用首次启动可能稍慢，这是重新生成缓存导致的正常现象。
- 删除 Xcode 共享缓存后，模拟器首次启动会按需重新生成必要缓存。
- 建议保持至少 15–20 GB 可用空间。

## 旧版命令行工具

桌面上的 **Mac磁盘清理工具.command** 仍然保留，可作为备用。日常使用建议直接打开图形化的 **Mac 空间清理.app**。
