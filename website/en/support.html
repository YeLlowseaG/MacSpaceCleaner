Help

Everything you need to install, verify, use and uninstall Mac Space Cleaner.

On this pageRequirementsInstallUse the appVerify the downloadUninstall

System requirements

  • macOS 14 or later
  • Apple Silicon and Intel Macs are supported
  • Xcode cleanup options appear only when Xcode is installed

Install

  1. Download MacSpaceCleaner-1.2.dmg.
  2. Open the DMG and drag Mac Space Cleaner into Applications.
  3. Open it from Applications. If macOS asks for access to a protected folder, review the prompt before granting access.

Use the app

  1. Wait for the scan to finish.
  2. Review Recommended cleanup and Optional cleanup. Use the details button to inspect their contents.
  3. Confirm the selected items and estimated recoverable space, then choose Clean selected.

Optional items are off by default. Personal data is never included in one-click cleanup.

Verify the download

SHA-256 for version 1.2:

0fc0b6f00940d0d5055a5a24fe678954f289b4d5fb63b153f4ea154d76a6d7f9

You can also download the SHA-256 checksum file and run:

shasum -a 256 MacSpaceCleaner-1.2.dmg

Uninstall

Quit the app, move Mac Space Cleaner from Applications to the Trash, then empty the Trash. The app does not install a background service or system extension.
