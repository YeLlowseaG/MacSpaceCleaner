Common sources

What usually takes up Mac storage?

App caches and logs

Browsers, chat apps and developer tools create temporary data that can be regenerated. Check its path and size first.

System Data

System Data is a category, not a removable folder. It may include caches, backups, virtual machines and local snapshots.

Old Xcode simulators

Developer Macs often have several old runtimes. Keep the newest version you need for each platform, then review older versions and shared caches.

Personal files

Downloads, iCloud files, photos and chat data are not caches. Back them up and confirm their purpose before moving or deleting them.

Common questions

What should I know before cleaning a Mac?

What should I delete first when my Mac is running out of storage?

Check the source first, then start with regenerable caches, logs, old Xcode simulators and developer caches. Review personal files separately.

Can I delete System Data directly?

No. System Data is a category rather than one folder. Find the actual source and review each item individually.

Can a website scan my Mac?

No. A browser page cannot directly access your local disk. Use a native app running on your Mac for a local scan.
