The interface

Every storage category has a clear safety boundary

Recommended caches, optional caches, old simulators and personal data are shown separately. You decide what happens after the scan.

What it finds

Everyday apps and developer tools

Recommended cleanup

Browser component caches, update caches, logs and regenerable content from tools such as npm, pnpm, bun, Homebrew and Playwright.

Optional cleanup

Other app caches, offline webpages, speech models, dynamic wallpapers and temporary resources from apps such as WeChat and WPS.

Xcode simulators

Finds old runtimes while keeping the newest version for each platform. Regenerable dyld shared caches can also be removed.

Personal data is view-only

Downloads, iCloud Drive, WeChat chat data and WPS backups are shown for reference and never included in one-click cleanup.

Safety boundaries

Only known cache paths are eligible

Before deleting anything, the app checks its allowlist, the directory type and symbolic links again. Paths that do not pass these checks are skipped.

  • Confirmation before cleanup
  • Optional items off by default
  • No file contents read or uploaded
  • Developer ID signed and Apple notarized
