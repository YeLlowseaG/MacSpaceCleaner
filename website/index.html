真实界面

哪些能删、哪些不能删，一眼分清

建议清理、可选缓存、Xcode 三类空间和个人数据分区呈现。每一类都有独立的勾选边界，扫描完成后再由你决定。

识别范围

从 Xcode 到日常应用缓存

Xcode 空间

旧版模拟器运行时按平台和版本逐个列出，自动标出每个平台的最新版；构建缓存（DerivedData）和真机调试支持文件也可以单独处理。这三类都是可重新生成的内容，删除不会影响源码和配置。看看它怎么判断 →

开发工具缓存

npm、pnpm、bun、Homebrew、Playwright 等工具留下的包缓存、临时执行缓存和下载缓存，都是可重新生成的中间产物。

应用缓存与日志

浏览器组件缓存、更新缓存、离线网页、语音模型、动态壁纸，以及微信、WPS 等应用的临时资源。这一类默认不勾选。

个人数据只读

下载、iCloud、微信聊天数据和 WPS 备份仅展示空间占用，不会进入一键清理。

安全边界

只处理明确允许的缓存路径

删除前会再次检查白名单、目录类型与符号链接。没有匹配安全规则的路径不会执行清理。

  • 清理前二次确认
  • 可选项目默认关闭
  • 不读取或上传文件内容
  • Developer ID 签名与 Apple 公证
